### 关闭端口 How to close TCP and UDP ports via windows command line

- 控制台查看运行

```
netstat -ano | findstr :端口号码
```

![](/uploads/upload_cfe4c684e06328f9d4922753b1073742.png)

可以看到使用该端口的应用程序PID号码.然后执行以下命令，关闭该进程，当然关闭进程之前，一定清楚它确实是你需要关闭的。

```
taskkill /pid 11704 /F
```
