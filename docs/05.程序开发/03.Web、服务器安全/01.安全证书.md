### 制作免费安全证书 https 请求

使用certbot 申请泛域名证书和自动续签

- 在你web服务器端下载certbot软件 [certbot下载](https://dl.eff.org/certbot-beta-installer-win_amd64.exe)
- 环境变量path路径添加安装目录bin文件夹，或直接在bin文件夹右键执行控制台程序
- 关闭服务端80端口
- 执行以下命令

```
certbot certonly --standalone
```

- 按照命令提示，同意相关协议，指定需要制作安全证书的域名地址，域名地址输入格式参考以下，www和不加www都需要填写，各域名直接空格隔开

```
www.toolsbox.org.cn toolsbox.org.cn md.toolsbox.org.cn
```

- 等待一会，证书会自动制作完成保存到安装目录live文件夹下面
- 然后如果是nginx发布的web服务，在nginx配置文件中指定证书路径到live文件夹的证书文件

```
listen       80;
listen 443 ssl;
server_name  www.toolsbox.org.cn toolsbox.org.cn;
# setup certificate
ssl_certificate C:/Certbot/live/toolsbox.org.cn/fullchain.pem;
ssl_certificate_key C:/Certbot/live/toolsbox.org.cn/privkey.pem;

```

- 续期时，先将nginx服务关闭，再执行cerbot -renew
