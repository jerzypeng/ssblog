## 常用命令

- ls，查看当前目录
- sudo rm -r -f path，删除当前目录path文件夹
- sudo cp [file] path, 将当前目录文件拷贝至path文件夹

## 常见问题

> terminal打不开

[中文匹配中文](https://blog.csdn.net/m0_59724528/article/details/128395442)

> [user] is not in the sudoers file

```
su -
sudo adduser [user] sudo
```

> Virtualbox Ubuntu 主机与虚拟机共享剪切板不起作用时

```
sudo apt-get update
sudo apt-get install virtualbox-guest-x11
sudo VBoxClient --clipboard
```

> 终端执行脚本是提示 ./[Script]: command not found

```
chmod +x [Script]
```
