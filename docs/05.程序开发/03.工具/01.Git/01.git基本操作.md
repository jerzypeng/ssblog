#### 克隆工程
```js
git clone https://gitee.com/hydrojip/psyp.git
```
#### 拉取
```js
git pull
```
#### 添加本地修改
```js
git add .
```
#### 提交本次修改
```js
git commit -m "注释"
```
#### 推送到源代码服务器
```js
git push
```

#### 强制回滚到指定版本
```js
git reset --hard 编号
```

#### 提交某个文件夹下面所有修改文件
```js
git add ./*
```
#### 提交指定文件
```js
git add ./trunk/syapp/SY.EFDCModelAdapter/Class/CIRPModel/CIRPRunModel.cs
```
### 注意本地修改了代码，如果不及时上传，同一分支，协作开发有人提交了，再拉取到本地会出现文件冲突的现象

#### 粗暴解决：
- 备份自己修改的文件到另一个地方
- 删除冲突的文件
- git checkout 从服务器获取文件
- git pull 拉取文件
- 把修改的内容重新复制进冲突文件
- 提交
