#### 应用

- 打开sqlite数据库 open sqlite database file

```
sqlite3 database.sqlite
```

- 查看sqlite数据库表名称 show sqlite database tables

```
sqlite> .tables
```

- 将sqlite数据库表导出为csv文件，export sqlite table to csv file

```
sqlite3 -header -csv database.sqlite "select * from table_name;" > out.csv
```
