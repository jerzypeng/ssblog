### matplotlib 保存图片不显示坐标轴的问题

当以下代码保存的图片不显示坐标轴时，增加bbox_inches参数值

```python=
fig.savefig('图片.png'),dpi=300)
```

```python=
fig.savefig('图片.png'),dpi=300,bbox_inches='tight')
```
