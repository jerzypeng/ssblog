### 导出当前项目的依赖包

使用pipreqs可以导出当前项目的依赖包
- 安装pipreqs
```
pip install pipreqs
```
- 在当前项目根目录，启动cmd，运行以下命令，导出当前项目包依赖
```
pipreqs . --encoding=utf8 --force
```

### 创建离线安装包

- 在可联网的机子上执行
```
pip download 包名
```
- 然后将包拷贝至部署机，执行
```
pip install --no-index --find-links 包目录 包名
```
