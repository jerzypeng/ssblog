## 简介

ArcGIS 是 Esri 公司开发的一套地图和地理信息系统（GIS）软件。它提供了创建、管理、分析和可视化地理数据的工具，以及创建交互式地图、3D 场景和应用程序的工具。ArcGIS 可用于支持广泛的应用，包括城市和区域规划、环境资源管理和基于位置的服务。ArcGIS 提供了一个灵活的平台，使组织能够存储、管理和共享其地理数据和地图，拥有基于云、基于 Web 和桌面的组件。
