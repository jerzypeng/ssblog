### 按面域切割线矢量（QGIS、Arcgis）

#### 应用场景示例

在开展地理环境建模时，往往我们首先是有一个确定的研究范围，而拿到的数据并不能确保全部位于研究范围以内，因此针对特定研究区域，会遇到按研究区域来切割（Clip）的需求。类似下图所示，蓝色线矢量为河流水系，浅蓝面矢量为我们的研究范围，我们需要按照研究区域面矢量数据提取研究范围内的河流水系，作为下一步工作的准备数据。下一步工作需求也许是为了制图，或是为了下一步作为研究区域二维模型网格剖分的控制线。

<!-- more -->

![](http://md.toolsbox.org.cn/uploads/upload_dae16f5a8996a864812d289dbb564b0d.png)

#### 操作步骤

- Arcgis
  - 打开工具箱（ArcToolsbox），依次选择 Analysis Tools -> Overlay -> Intersect 工具
  - 在工具窗口的 Input Features 项里选择需要相交计算的线矢量、面矢量数据名称，执行计算
- QGIS
  - 在右侧栏搜索框输入：Intersection 点击搜索按钮，或在菜单依次选择 Vector -> Geoprocessing Tools -> Intersection
  - Input Layer 选择需要相交计算的线矢量文件，Overlay Layer 选择需要相交计算的面域矢量文件
- 运行结果如下图所示，绿色线矢量数据即为我们的需求
