### QGIS加载CAD等高线数据生成DEM

要使用QGIS从AutoCAD DWG文件生成DEM（数字高程模型），可以按照以下步骤进行操作：

打开QGIS并将DWG文件加载到项目中，方法是单击菜单栏中的“Layer”，然后选择“Add Layer”，并选择“Add Vector Layer”。在“Data Source Manager”对话框中，选择“AutoCAD DXF”格式，并浏览到DWG文件的位置。
<!-- more -->

加载DWG文件后，您需要创建一个表示高程数据的点图层。为此，请单击菜单栏中的“Layer”，然后选择“Create Layer”，并选择“New Shapefile Layer”。在“New Vector Layer”对话框中，将Geometry Type设置为“Point”，并将CRS（坐标参考系统）设置为与DWG文件匹配。

在新点图层的属性表中，通过单击“Toggle editing”，然后单击“Add Field”按钮来为高程数据创建一个字段。将字段命名为“Elevation”，并将数据类型设置为“Decimal number (real)”。

接下来，使用处理工具箱中的“Interpolation”工具（位于菜单栏下的“Processing”>“Toolbox”中）从点图层创建栅格DEM。在“Interpolation”对话框中，将点图层设置为Input layer，将“Elevation”字段设置为Interpolation attribute，并选择插值方法（例如“Inverse Distance Weighting”或“Kriging”）。

创建栅格DEM后，可以调整显示设置以可视化高程数据。右键单击图层图层，并选择“Properties”打开“Layer Properties”对话框。转到“Symbology”选项卡，并选择颜色斜坡以表示高程值。

您还可以添加一个Hillshade图层，以增强DEM的可视化效果。为此，请单击菜单栏中的“Layer”，然后选择“Create Layer”并选择“New Raster Layer”。在“New Raster Layer”对话框中，选择“Hillshade”作为类型，并将DEM图层选择为输入层。根据需要调整显示设置。

最后，您可以将DEM和Hillshade图层导出为栅格文件，方法是右键单击层图层，并选择“Export”>“Save As”。选择文件格式（例如GeoTIFF），并设置输出文件位置和CRS。
