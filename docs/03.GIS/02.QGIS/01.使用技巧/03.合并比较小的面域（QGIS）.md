### 合并比较小的面域（QGIS）
今天为大家分享一种基于开源QGIS软件合并较小面域的方法。
#### 应用场景示例

在处理区（流域）各类图层时，因为我们需要根据研究目的进行相应的切开、合并或者不同数据的融合等工作，避免不了会出现一些间隙或者重叠的小区域，类似下图黄色区域，考虑数据应用需求，这块区域不作为单独研究对象，可将其归到邻近域内，因此需要将其合并到邻近的面域。

![](http://md.toolsbox.org.cn/uploads/upload_7827714c4c7dc5c0d255d525104a3f4d.png)

#### 操作步骤

- 首先打开面域矢量数据的属性表，选择字段计算功能，计算面域面积
- 按面积大小排序，找到我们需要合并的面积阈值
- 然后工具搜索框搜索【select by expression】工具
- 使用 Select by expression 工具
- 选择面积字段，如：BASINAREA，输入选择表达式​：<1000 m2
- 点击【run】选中阈值范围内的小面域

![](http://md.toolsbox.org.cn/uploads/upload_039e323450aefc1469f16cbee55f946e.png)

- 然后在工具搜索框搜索 Eliminate selected polygons 工具，利用该工具将选中的面域合并的邻近面域

![](http://md.toolsbox.org.cn/uploads/upload_aa3b75714112f0ced8f20509ad55dfdf.png)
