### 时间控制闸门开口 time control gate opening

```
Gate Openings= 10 # hec-ras 5.0.5 版本测试 开口时间序列最大只能是10，
```

可通过修改时间间隔来使得闸门控制时间序列长度与模拟时间长度保持一致

```
Gate Time Interval=1HOUR
```

### 水位边界时间序列存储格式 Stage Hydrograph data format
