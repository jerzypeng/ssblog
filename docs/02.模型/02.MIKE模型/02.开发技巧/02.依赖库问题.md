## MIKE模型接口开发依赖库问题

很多人都说MIKE模型不开放等等，其实还是对MIEK模型的不够了解。MIKE模型在差不多05版本以后，操作界面逐渐通过.net C#改写，逐渐有了比较规范的接口定义，是可以通过调用相关Dll来实现对模型的实时交互的。自2014版本后就有了正式的SDK包。但仍然有一些早期的c++等语言写的动态链接库库，在C#库中通过DllImport调用，这些依赖库需要拷贝到运行目录，否则程序会提示找不到依赖库的错误。同时，对于依赖这些库编译的Dll，需要严格注意其架构是否对应，x86还是x64，以及对应的MIKE版本。

如下为主要依赖的一些库。

```C#
DHI.DHIfl.dll
MzLanguage.dll
pfs2004.dll
ufs.dll
ams2004.dll
Dhifl.dll
eum.dll
```
