#### 新编译的64位Delft3D计算引擎

> 发布于新浪博客，时间：2014-07-29 15:37:41 分类: .net编程、模型开发 [原文](http://blog.sina.com.cn/s/blog_5e778a9d0102uyiv.html)

基于Delft3d开源Trunk目录最新版本改用64位编译而成，经粗略水流计算测试，没发现大问题。

[点击下载 Download](http://toolsbox.org.cn/download/delft3d/delft3d.zip)

Delft3D开源工程下载地址：<http://oss.deltares.nl/web/delft3d>

若运行不了，提示缺少dll等问题，按以下解决方法。

1.确保安装有c++ redistrutable 2010 x64，如没有在这里下载安装，<http://www.microsoft.com/en-us/download/details.aspx?id=14632>

2.确保安装有intel visual fortran运行库（Redistributable libraries for Intel C++ and Visual Fortran Composer XE 2013 for Windows），下载地址：<https://software.intel.com/en-us/articles/redistributable-libraries-for-intel-c-and-visual-fortran-composer-xe-2013-for-windows>，update2

3.如有了以上环境，仍然不能运行的，可下载Dependency Walker（下载地址：<http://dependencywalker.com/>）查看缺少的dll，将相关dll拷贝至程序目录。

经过以上步骤，基本可以解决问题，如仍然有问题，可以咨询deltares（<http://oss.deltares.nl/web/delft3d>），或可咨询博主协助完成。
