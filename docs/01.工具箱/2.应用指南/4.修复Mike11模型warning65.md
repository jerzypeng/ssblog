# 修复Mike11模型warning65

指定需要修复的断面文件**（先备份）**，配套的河网文件及计算输出的log日志文件，点击【端点增加断面 交叉处去高抹平】按钮，待日志显示任务执行成功后，本地断面文件即已更新。重新执行模型计算，如仍有warning65消息提示，再执行该过程，如此反复，直至全部消除。
