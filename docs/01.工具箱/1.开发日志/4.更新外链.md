# 更新外链

原.net程序用process.start方法打开浏览器，在Win10系统不管用了。

```c#
Process.start(new ProcessStartInfo("http://www.toolsbox.org.cn"))
```

修复为以下代码。

```c#
Process.Start("explorer.exe", "http://www.toolsbox.org.cn");
```
